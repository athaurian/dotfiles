# Glossary

This page defines terms the guides use but do not explain. Each definition
stands on its own. The reference column links to an authoritative external
source for readers who want more detail.

## Color and image processing

| Term                                                    | Meaning                                                                                                                                                                                                                                                                    | Reference                                                                                                  |
| :------------------------------------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------- |
| <a id="clut"></a>CLUT                                   | A color lookup table: a mapping from an input color to the color that replaces it when a correction is applied.                                                                                                                                                            | [Palette (computing)](https://en.wikipedia.org/wiki/Palette_%28computing%29)                               |
| <a id="hald-clut"></a>Hald CLUT                         | A CLUT encoded as a square image whose pixel positions enumerate the colors of a color space. Recoloring looks up each source color at the corresponding position and interpolates between entries. Level N yields an N³ × N³ image; level 16 covers all 8-bit RGB values. | [Quel Solaar, Hald CLUT](https://www.quelsolaar.com/technology/clut.html)                                  |
| <a id="lutgen"></a>`lutgen`                             | The upstream command-line utility that interpolates a palette into color lookup tables and applies them to images.                                                                                                                                                         | [lutgen-rs](https://github.com/ozwaldorf/lutgen-rs), [lutgen wiki](https://ozwaldorf.github.io/lutgen-rs/) |
| <a id="rbf-interpolation"></a>RBF interpolation         | Radial basis function interpolation, which estimates intermediate colors from neighboring palette samples using radial kernels.                                                                                                                                            | [Radial basis function interpolation](https://en.wikipedia.org/wiki/Radial_basis_function_interpolation)   |
| <a id="shepard-interpolation"></a>Shepard interpolation | Inverse distance weighting, which computes each intermediate color as a weighted mean of nearby palette colors, with weights that fall as distance increases.                                                                                                              | [Inverse distance weighting](https://en.wikipedia.org/wiki/Inverse_distance_weighting)                     |

## Packaging and configuration

| Term                                                   | Meaning                                                                                                                            | Reference                                                                                 |
| :----------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------- |
| <a id="x86-64-v3"></a>`x86-64-v3`                      | A microarchitecture level of the x86-64 instruction set. Binaries built for it require a CPU from roughly Haswell or Zen 1 onward. | [Microarchitecture levels](https://en.wikipedia.org/wiki/X86-64#Microarchitecture_levels) |
| <a id="sigill"></a>`SIGILL`                            | The signal raised when a process executes an instruction its CPU does not support.                                                 | [Signal (IPC)](https://en.wikipedia.org/wiki/Signal_%28IPC%29#SIGILL)                     |
| <a id="aur"></a>AUR                                    | The Arch User Repository, a community-maintained collection of build recipes installed here through `paru`.                        | [Arch User Repository](https://wiki.archlinux.org/title/Arch_User_Repository)             |
| <a id="paru"></a>`paru`                                | An AUR helper that builds and installs packages from the AUR.                                                                      | [paru](https://github.com/Morganamilo/paru)                                               |
| <a id="chezmoi-triggers"></a>chezmoi trigger           | A `run_onchange_*` script that chezmoi reruns when its rendered contents change.                                                   | [Target types](https://chezmoi.io/reference/target-types/)                                |
| <a id="chezmoi-special-files"></a>chezmoi special file | A file such as `.chezmoiignore`, `.chezmoiremove`, or `.chezmoiroot` that controls source layout or deployment.                    | [Special files](https://chezmoi.io/reference/special-files/)                              |

## Display and session

| Term                                      | Meaning                                                                                                                                            | Reference                                                                                       |
| :---------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------- |
| <a id="wayland"></a>Wayland               | The display protocol used by Sway on `thinkpad`. Clients do not draw to the screen directly; the compositor presents their surfaces.               | [Wayland](https://en.wikipedia.org/wiki/Wayland_%28protocol%29)                                 |
| <a id="x11"></a>X11                       | The older display protocol used by i3 on `optiplex`, where a separate compositor can be added for effects.                                         | [X Window System](https://en.wikipedia.org/wiki/X_Window_System)                                |
| <a id="compositor"></a>compositor         | The component that combines window surfaces into the final image. Under Wayland this role belongs to the window manager; under X11 it is separate. | [Compositing window manager](https://en.wikipedia.org/wiki/Compositing_window_manager)          |
| <a id="systemd-user-unit"></a>user unit   | A systemd service definition managed for a single user rather than system-wide.                                                                    | [systemd/User](https://wiki.archlinux.org/title/Systemd/User)                                   |
| <a id="session-target"></a>session target | A systemd target that groups the units belonging to a graphical session, such as `sway-session.target`.                                            | [systemd.target](https://www.freedesktop.org/software/systemd/man/latest/systemd.target.html)   |
| <a id="oneshot-unit"></a>oneshot unit     | A service that runs once to completion before units that depend on it start.                                                                       | [systemd.service](https://www.freedesktop.org/software/systemd/man/latest/systemd.service.html) |
| <a id="dpms"></a>DPMS                     | Display Power Management Signaling, the X11 mechanism that powers a display down after a period of inactivity.                                     | [VESA DPMS](https://en.wikipedia.org/wiki/VESA_Display_Power_Management_Signaling)              |

## System interfaces

| Term                                        | Meaning                                                                                                                   | Reference                                                                                       |
| :------------------------------------------ | :------------------------------------------------------------------------------------------------------------------------ | :---------------------------------------------------------------------------------------------- |
| <a id="sysfs"></a>sysfs                     | The kernel filesystem under `/sys` that exposes devices and their driver attributes, including battery charge thresholds. | [sysfs](https://en.wikipedia.org/wiki/Sysfs)                                                    |
| <a id="udev"></a>udev                       | The device manager that runs rules in response to kernel device events.                                                   | [udev](https://wiki.archlinux.org/title/Udev)                                                   |
| <a id="d-bus"></a>D-Bus                     | The interprocess message bus through which desktop services exchange signals and method calls.                            | [D-Bus](https://www.freedesktop.org/wiki/Software/dbus/)                                        |
| <a id="mpris"></a>MPRIS                     | The D-Bus specification for media-player metadata and playback control.                                                   | [MPRIS](https://specifications.freedesktop.org/mpris-spec/latest/)                              |
| <a id="geoclue2"></a>GeoClue2               | The D-Bus location service that resolves location without an outbound request.                                            | [GeoClue](https://www.freedesktop.org/software/geoclue/)                                        |
| <a id="gsettings"></a>GSettings             | The GLib settings system used here to store GTK theme, icon, and font state outside the dotfiles.                         | [GSettings](https://docs.gtk.org/gio/class.Settings.html)                                       |
| <a id="polkit"></a>Polkit                   | The authorization framework that lets unprivileged processes request privileged actions.                                  | [polkit](https://www.freedesktop.org/software/polkit/docs/latest/)                              |
| <a id="xdg_cache_home"></a>`XDG_CACHE_HOME` | The XDG base-directory variable that locates user-specific cached files.                                                  | [XDG Base Directory Specification](https://specifications.freedesktop.org/basedir-spec/latest/) |

## Tooling and Git

| Term                        | Meaning                                                                                           | Reference                                                            |
| :-------------------------- | :------------------------------------------------------------------------------------------------ | :------------------------------------------------------------------- |
| <a id="rclone"></a>`rclone` | The command-line tool that transfers and synchronizes files to cloud storage.                     | [rclone documentation](https://rclone.org/docs/)                     |
| <a id="openpgp"></a>OpenPGP | The open standard for cryptographic signing used here for Git commits and tags.                   | [OpenPGP](https://en.wikipedia.org/wiki/Pretty_Good_Privacy#OpenPGP) |
| <a id="rerere"></a>`rerere` | Git's mechanism for recording a conflict resolution and reusing it when the same conflict recurs. | [git-rerere](https://git-scm.com/docs/git-rerere)                    |
| <a id="zdiff3"></a>`zdiff3` | A Git conflict style that includes the common ancestor in conflict markers.                       | [git-merge-file](https://git-scm.com/docs/git-merge-file)            |
