# Pickers

`$mod+d` opens the application launcher, fuzzel on `thinkpad` and rofi on
`optiplex`.

Each power shortcut opens a confirmation menu in the same picker before it runs.

| Binding                | Action    |
| ---------------------- | --------- |
| `$mod+Shift+BackSpace` | Power off |
| `$mod+Shift+r`         | Reboot    |
| `$mod+Shift+z`         | Suspend   |
| `$mod+Shift+e`         | Log out   |

Press `Return` to confirm or `Esc` to cancel.
