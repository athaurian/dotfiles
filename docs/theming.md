# Themes

`$mod+Shift+t` flips between dark and light on the spot. To change the actual
colors, edit
[`meta/palette.toml`](https://github.com/athaurian/dotfiles/blob/main/meta/palette.toml)
and run `make dark` or `make light`. [Palette system](palette-system.md) covers
those targets.

`sw` handles wallpapers. `sw --set` puts an image on the desktop, `sw --next`
rotates to the next one, `sw --restore` brings back the last one, and
`sw --help` lists the rest.
